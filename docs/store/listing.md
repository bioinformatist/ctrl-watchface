# CTRL Watchface Store Listing

## Description

### English

CTRL Watchface is an iKun-themed Connect IQ watch face for Garmin fēnix 7X. It keeps the display simple: a monochrome CTRL dance animation in the center, time and date at the top, and glanceable Garmin metrics around the dial.

The animation advances only while the watch face is awake. In low-power sleep mode, the face stays static to avoid unnecessary refreshes. Metrics include heart rate, steps, Body Battery, and battery level when the device makes those values available.

### 简体中文

CTRL Watchface 是一款为 Garmin fēnix 7X 设计的 iKun 主题 Connect IQ 表盘。主画面以黑白 CTRL 舞蹈动画为中心，上方显示时间和日期，周围展示常用 Garmin 指标。

动画仅在表盘唤醒时播放；进入低功耗待机后，表盘保持静态，以减少不必要的刷新。可显示心率、步数、身体电量和手表电量，具体数值取决于设备可用数据。
